    输入phone：String，大陆 11 位手机号

    输入Bearer accessToken 或 query accessToken
    输出透传 X-User-Id 等 Header 或 401

    • ▶L2 流转：白名单 → 解析 JWT → 读 session → 比对 active-session → 写 Header
      • ▶L3 JwtGlobalFilter.filter
        • ▶L4 校验项与失败码
          • ▶L5 内部校验顺序与 Redis 读取

            [简略] 无 token→401；JWT 无效→401；session 非 ONLINE→401；active-session 不一致→「其他设备登录」；BANNED/CANCELLED→401。

            读 user:session:{sessionId} 反序列化为 UserSessionVO，要求 status=ONLINE。
