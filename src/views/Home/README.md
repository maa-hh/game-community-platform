# 官网首页 `views/Home`

官网首页对应根路径 `/`，展示品牌宣传视频与社区入口。

| 文件         | 职责                                          |
| ------------ | --------------------------------------------- |
| `index.tsx`  | Hero 视频、登录入口、进入社区按钮与宣传片弹窗 |
| `style.less` | 官网首页的全屏视频与内容叠层样式              |

登录和注册由根布局中的全局 `AuthModal` 提供；已登录用户点击「进入社区」会进入 `/community`。
