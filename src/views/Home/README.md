# 官网首页 `views/Home`

官网首页对应根路径 `/`，由 `HomeLayout` 提供顶栏但不使用站内限宽内容盒。页面职责是品牌宣传、视频背景/弹窗、主题切换提示和社区入口，不承载登录表单本身。

| 文件         | 职责                                                                  |
| ------------ | --------------------------------------------------------------------- |
| `index.tsx`  | Hero 视频、登录入口、进入社区按钮、宣传片弹窗；根据登录态决定入口文案 |
| `style.less` | 全幅背景、渐变叠层、响应式内容位置；高度使用 `--app-header-height`    |

## 交互约束

- 登录/注册由 RootLayout 中的全局 `AuthModal` 提供；页面通过 `useAuthModal` 打开。
- 已登录用户点击进入社区进入 `/community`，不把用户强制送到 `/feed`。
- 视频只负责官网宣传，不复用详情页 16:9 点播播放器；用户偏好减少动效时应保留可读的静态入口。
- 页面继续遵守 `DESIGN.md` 的橙色主色和深色首页例外，不在页面内新增另一套全局 token。
